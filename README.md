# Slovo site

Website of the Slovo app for GitHub Pages: landing page, Privacy Policy, Terms of Use and Support in 14 languages.

English lives at the root, other languages in their own folders (`ru/`, `de/`, ...), four pages each: `index.html`, `privacy.html`, `terms.html`, `support.html`.

This repository holds the built site only. The sources (copy per language, the build script and the screenshot script) are kept separately; changes are made there and the `site/` output is copied here.
